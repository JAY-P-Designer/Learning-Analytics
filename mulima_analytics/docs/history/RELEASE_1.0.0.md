# Learning Analytics 1.0.0

A numeração pública do plugin passa a ser **1.0.0**. Este pacote conserva as
funcionalidades e correcções incluídas na versão 1.5.5: filtros hierárquicos,
relatórios, pontuação, fóruns, trabalhos, presenças, exportações, traduções e
configurações.

- Componente: `local_learning_analytics`.
- Directório: `local/learning_analytics`.
- Versão apresentada (`$plugin->release`): `1.0.0`.
- Versão interna (`$plugin->version`): `2026100205`.
- Moodle mínimo: 4.0 (`2022041900`).

O número interno continua a aumentar, permitindo actualizar a versão 1.5.5
já instalada. A alteração da numeração pública não modifica a base de dados
nem os cálculos dos relatórios.

Instalar como actualização, concluir **Administração do site > Notificações**
e limpar as caches do Moodle. As notas das versões anteriores são mantidas
como histórico de desenvolvimento.
